# Local folder cleanup, 2026-10-26

This review measured the entire local project folder, including hidden files,
ignored outputs, nested checkouts and dependencies. Directory links were not
followed. Sizes below are logical file sizes, in decimal GB, rather than a disk
allocation measurement.

The initial inventory contained 633,343 files totaling 53,096,940,669 bytes
(53.10 GB). Most space was in `web-ext-artifacts/` (43.65 GB), followed by
`scratch/` (4.93 GB) and `research/` (2.78 GB).

## Safe removals

Removed 608 temporary browser-test directories containing 311,915 files,
totaling 21,576,112,237 bytes (21.58 GB):

| Generated directory pattern | Directories | Bytes removed |
| --- | ---: | ---: |
| `learning-chrome-*` | 289 | 12,380,854,610 |
| `learning-profile-*` | 291 | 8,147,816,277 |
| `layout-chrome-*` | 5 | 162,978,409 |
| `layout-profile-*` | 5 | 199,133,915 |
| `smoke-chrome-*` | 7 | 235,286,378 |
| `smoke-chrome-profile-*` | 7 | 362,528,429 |
| `smoke-firefox-*` | 4 | 87,514,219 |

All removals were immediate children of `web-ext-artifacts/`, with the exact
six-character suffixes generated by the maintained browser-test scripts. Each
directory was older than 24 hours at selection, with no descendant modified
since 2026-10-25 17:10 Europe/Copenhagen. Recursive inspection found no links,
Git metadata or special files. A process-command-line check found no running
browser, test or Git process referencing a selected directory. Git tracked none
of these paths. Absolute target paths were checked before deletion.

The detailed local inventory summary, removal plan, process check and per-folder
results are retained in ignored `scratch/cleanup-20261026/`.

## Material retained

- All tracked project files, local development changes, engines and selectable
  assets. No safe tracked-file deletion was established by this review.
- Test directories from the most recent 24 hours, including current UI work.
- All 83 historical release directories, ZIP archives, release records and
  audit screenshots; the latest release's unpacked sources remain available
  to the browser-test scripts.
- The 1.46 GB `web-ext-artifacts/cleanup-20261003/` recovery archive and Git
  preservation repositories. Their size alone does not justify deletion.
- Research evidence and `research/runs/`, including verification checkouts.
  Historical provenance and failed runs remain required by research policy.
- `scratch/` and `.scratch/` material, including registered Git worktrees,
  alternative implementations, index backups and investigation outputs whose
  retirement was not established.
- Git history, installed dependencies, finished marketing media and cached
  narration. Removing these would discard useful state or require setup again.

Subtracting the removed file sizes from the initial inventory leaves about
31.52 GB. This is an estimate; concurrent development and filesystem allocation
can change the observed total.

## Verification

- Every selected directory was removed, with no deletion failures.
- `npm run verify:engines` passed for both bundled engines.
- `npm run verify:source` passed.
- SHA-256 checks passed for the latest source, Chrome and Firefox ZIP archives;
  both retained browser source directories still contain their manifests.
- The documentation diff passed `git diff --check`.

No application behavior changed, so application and browser test suites were
not rerun solely for this cleanup. No remote Git operation was performed.
