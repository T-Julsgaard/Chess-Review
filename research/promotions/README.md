# Promotion decisions

Create `P###-short-name.md` from [the promotion template](../templates/promotion.md)
when evidence is ready for an implementation assessment. Register proposed,
deferred, rejected, accepted and implemented decisions in the index. Record
which components were selected and why, with links to supporting findings.

Acceptance is a maintainer decision; implementation and release are separate
states. An experiment never edits the active calibration automatically.
Retain decision records even when the candidate is rejected or superseded.

No promotions have been proposed yet.
