## Population, selection and provenance

2,000 normalized standard-start public blitz games from June-August 2026
Lichess archives: 1,400 train, 300 validation, 300 test; 4,000 unique recorded
player identities. Selection balanced five focal-rating bands and used retained
archive byte-range frames, rather than sampling the whole blitz population.
Both colors stay together; no player crosses roles (E001 check). Rating targets
are the game's recorded platform rating, not FIDE Elo or independently measured
strength. Normalized records omit rating deviation, clocks and longitudinal
strength evidence.

Sources/license: [CC0 archives](https://database.lichess.org/), recorded URLs,
retrieval dates, ranges and frame hashes in
[sources.json](../../../tools/calibration/public/sources.json). Whole-archive
checksums were not verified. Existing normalized schema contains game ID,
source/month, focal band/color, role, deterministic order, player ID/rating/color,
result, time control/category/date and UCI mainline. Raw provenance is public;
IDs are needed for overlap checks. No private account data is being collected.

Reconstruct independently with Node.js 24 or later, from the repository root:

```sh
node research/datasets/D001-public-baseline/reconstruct.mjs --download
node tools/calibration/reproduce-public.mjs
```

The first command retrieves missing original fragments (282,463,458 bytes total)
from the exact recorded HTTPS ranges, checks their hashes, and caches them under
ignored `research/runs/D001-reconstruction/frames/`. Omit `--download` for a fully
offline reconstruction using that cache. It compares the complete normalized
games, selection/splits, raw locators and deterministic report with the retained
evidence; it never replaces public inputs or retained evidence. No npm packages,
Git history or engine searches are required. The second command refits the
published calibration using the retained engine observations.

The historical sampler from `17a0e9443776d6089364f34ab9327922e38a9cb7`
is retained in `research/d001-format.mjs`. Its original algorithm is unchanged;
the acquisition wrapper adds bounded requests and verification. The record and
manifest pin LF-normalized SHA-256 hashes of the sampler, wrapper, frame decoder,
chess parser and shared checks. Verification ran on Node.js v24.14.1, Windows x64.
Cached replay also passed in a clean copy without Git metadata, npm dependencies
or network requests, with filesystem permissions restricted to that copy.
All 862,250 complete records were scanned; 389,693 passed header eligibility.
The exact 2,000 selected games match the original normalized JSONL SHA-256
`d8a99c4100179454de87ec3c0e9b316165c279c44b0675124db0c3324c1295c5`.
Selection rejected 96 short games and 71 shared-player candidates; zero invalid
mainlines or duplicate selected games were counted.

This extends E001's historical audit, which did not reconstruct acquisition.
It does not establish representative sampling, original test secrecy, stable
playing strength or fresh confirmation. Provisional-rating status is unavailable.
The recorded engine observations have not been regenerated by this command.
Legacy `gameOrigin()` summaries remain available for exact replay of existing
blinded packs; preflight `--game` uses current provenance and the raw locator.
