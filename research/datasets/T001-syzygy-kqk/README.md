separate from the unchanged game-source registry and loader. These are computed
tables, not imported games or diagrams. Exact original URLs, retrieval timestamps,
sizes, checksums and admission receipts are in manifest.json. Two retained files
total 5,664 bytes; KQK captures close to the KK mechanical draw base case.

Permission is the generator author's express redistribution grant, retained
against immutable upstream commit 0bb8aeee525f364bb750f96df312a1a7c9b54398 in
../evidence/syzygy-kqk-permission-2026-10-10.md. This is not a legal determination
or a CC0 assertion. Publisher SHA256 entries are retained separately; they are
integrity metadata, not an independent mathematical validation of the tables.

Offline verification: call openResearchTablebases() from
research/tablebase-data-policy.mjs. It checks the game guard, registered source,
permission/checksum notes, manifest origins, table headers, lengths and hashes
before returning a usable directory. It refuses changed or missing evidence.
For an explicitly authorized reacquisition, reverify source terms first, then run
node research/experiments/E141-admitted-kqk-tablebases/code/acquire.mjs from the
repository root. Existing matching files are reused; no position API is involved.
