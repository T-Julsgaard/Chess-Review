# Experiment records

Create `E###-short-name/plan.md` from [the template](../templates/experiment.md).
After starting, create `RESULT.md` using its result section. Keep the committed
plan as the original protocol; append dated amendments with exposure status.

Use `code/`, `config/` and `evidence/` within that folder when needed. Candidate
models stay here. Bulk artifacts go in ignored `../runs/<id>/<run-id>/` and must
have a retained manifest and retrieval/rebuild recipe. Register each experiment
in [INDEX.md](../INDEX.md), including negative, inconclusive and invalid outcomes.

See [the index](../INDEX.md) for registered and completed experiments.
