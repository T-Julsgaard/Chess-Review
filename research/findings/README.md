# Findings

Create `F###-short-name.md` from [the finding template](../templates/finding.md).
A finding is a durable conclusion with bounded claims and linked evidence;
an experiment is the work that supports or challenges it. One finding may cite
several experiments. Keep negative and inconclusive findings discoverable to
prevent repeated dead ends. Update the index with outcome and evidence maturity.

When later evidence changes a conclusion, append a dated revision and link the
superseding finding. Preserve the original result and the reason for the change.
