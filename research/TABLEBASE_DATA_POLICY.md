# Computed tablebase admission — tablebase-data-v1

Adopted 2026-10-10 for generated endgame data, separately from public-data-v1
game artifacts. Explicit publisher redistribution permission is recorded as its
own grant, never mislabeled CC0. Only exact exports in
datasets/tablebase-approved-sources.json qualify. The initial namespace is T001,
KQvK WDL/DTZ only, with mechanical KK capture closure. No game/diagram/position
API responses or unrelated material can be admitted by this registration.

The shared tablebase-data-policy.mjs source gate checks public/free status, grant,
purpose, exact export, hash-bound permission and publisher checksum metadata
before acquisition. Its dataset gate additionally checks complete manifest,
retrieval URLs, expected byte sizes/SHA256, binary headers and origin format
before probing. Every entry also calls the existing openResearchData D001 test
guard; game approval does not substitute for this tablebase admission.

Retain exact small table files, acquisition metadata, probe-code/runtime hashes,
full authored position histories, raw WDL/DTZ and rule-model limitations. Checksums
prove byte identity, not outcome truth; signed/provenance claims must not exceed
the evidence. DTZ may be rounded and zero-counter WDL is not a general result
for arbitrary clocks/repetition history. Missing files/subtables, changed bytes,
unknown sources, unbound probe implementations and unsupported material refuse.

Existing game registry/validator and frozen evidence are unchanged. This addendum
changes DATA_POLICY.md's metadata hash; the E140 support record remains bound to
the historical version. Reproduce that old metadata-bound record at its frozen
source, or explicitly validate compatible behavior under a new source record;
never rewrite old output hashes or call them unchanged. Future namespace/license/
format expansions need another documented admission revision and focused checks.
