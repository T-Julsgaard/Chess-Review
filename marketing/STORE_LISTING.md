Independent, one-click chess analysis for games from sites like Chess.com and Lichess.

Completely free, with every feature available to everyone.

Now includes 50,000 offline puzzles and interactive opening lessons.

KEY FEATURES
• Player accuracy — See estimated accuracy scores for both players.
• Best-move arrows — See the engine’s recommended move directly on the board.
• Move classifications — See how the engine rates each move.
• Evaluation graph — Track how the advantage shifted throughout the game.
• Performance estimates — See an estimated performance rating for each player.
• Opening detection — Identify the opening played using the built-in opening book.
• Interactive analysis — Explore your own variations with live Stockfish evaluation.
• 50,000 offline puzzles — Practise tactics with difficulty and theme filters.
• Interactive opening lessons — Learn the ideas behind the moves and practise from either side.

HOW IT WORKS
Open a game on Chess.com or Lichess and start a review. Chess Review uses Stockfish to analyze the game directly in your browser, with all analysis running locally on your device.

Get a complete move-by-move review with accuracy scores, move classifications, evaluations, recommended moves, estimated performance ratings, and opening information.
